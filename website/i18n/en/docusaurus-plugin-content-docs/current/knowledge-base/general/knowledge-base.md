This site turns experience from real projects and workflows into durable technical knowledge. Its long-term topics are **AI automation, software engineering, n8n, knowledge management, and open-source practice**.

## What you will find here

- **AI automation**: reliable integrations across models, tool calls, agents, and business processes.
- **Software engineering**: practical decisions in architecture, code quality, testing, delivery, and debugging.
- **n8n**: workflow design, node integrations, operations, and reusable automation patterns.
- **Knowledge management**: Markdown, Obsidian, bidirectional links, and knowledge graphs.
- **Open source**: open collaboration, project maintenance, and reusable tooling.

## Editorial principles

Each article aims to state its context, constraints, executable steps, and verification evidence. Ideas that have not been validated in practice are distinguished from stable conclusions rather than presented as established answers.

Content is stored as standard Markdown and connected through categories, tags, and `[[WikiLink]]` references. During each build, these relationships are added to the document knowledge graph so readers can continue from one article into related material.

## Where to start

To publish your own notes, begin with the [[guides/obsidian-publishing-guide|Obsidian publishing guide]], then use the [[reference/markdown-publishing-reference|Markdown publishing reference]] to check front matter, links, and image paths.

All content and site code are maintained openly on GitHub. Use [GitHub Discussions](https://github.com/zj75968-cpu/docusaurus/discussions) to report errors, contribute examples, or suggest new topics.
